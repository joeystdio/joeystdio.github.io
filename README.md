# joeystdio.github.io

Personal site & portfolio of **Joey Stevense** ([@joeystdio](https://github.com/joeystdio)) — lead software engineer building agentic AI that ships.

Static single-file site (`index.html`), no build step. Hosted with GitHub Pages.

## Deploy

This repo is a [GitHub Pages user site](https://pages.github.com/): because it's named `joeystdio.github.io`, GitHub serves `index.html` from the default branch at **https://joeystdio.github.io**.

To publish:
1. Create a public repo named exactly `joeystdio.github.io`.
2. Push this folder's contents (at minimum `index.html`) to the `main` branch.
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `root`.
4. Live in ~1 minute at https://joeystdio.github.io.

## Custom domain (optional)

To serve at `joeystdio.dev` instead, add a `CNAME` file containing `joeystdio.dev`, then point the domain's DNS at GitHub Pages.
